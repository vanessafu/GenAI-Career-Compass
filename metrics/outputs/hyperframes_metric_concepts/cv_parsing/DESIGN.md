# CareerCompass Metric Concept: CV Parsing Field Score

## Style Prompt
Clean modern presentation visual for a fixed-fixture parser metric. The image should feel like a high-quality slide reference, not a product dashboard. Use exact metric values, large type, restrained chart shapes, and clear whitespace. Do not present the score as broad production accuracy.

## Colors
- Background: #f8f5ee
- Ink: #151821
- Muted text: #667085
- Primary accent: #2458d8
- Secondary accent: #0f766e
- Warning accent: #c98218
- Soft line: #ded8ca

## Typography
- Display and body: Aptos / Segoe UI fallback
- Data: Cascadia Mono / Consolas fallback

## What NOT to Do
- No generated or inferred numbers.
- No dense dashboard chrome.
- No decorative blobs or stock imagery.
- No tiny labels below 18px.
